# Ключевые решения

Черновик. Перепиши каждый пункт своими словами.

1. **Браузер вместо API.** Публичный API поиска вакансий hh.ru с 2026 года закрыт для неавторизованных запросов, поэтому данные берутся через Playwright под сессией пользователя с постоянным профилем.
2. **Человек подтверждает каждый отклик.** Снижает риск блокировки аккаунта и защищает от плохих писем: LLM предлагает, человек решает.
3. **Локальная модель для оценки.** Резюме и переписка — персональные данные; локальная Qwen2.5 через Ollama не отправляет их наружу и бесплатна при сотнях вакансий в день.
4. **Постобработка ответа модели.** 7B-модель нарушает инструкции: оставляет плейсхолдеры, путает фамилию, вставляет ИИ-штампы. Детерминированные правки после генерации надёжнее, чем ещё одно правило в промпте.
5. **Контекст 8192 токена.** Резюме + вакансия + инструкции занимают около 5 тыс. токенов; при стандартном контексте Ollama часть промпта молча обрезалась бы.
6. **Межпроцессная блокировка на Ollama.** Два агента (hh и Habr) одновременно нагружали одну 7B-модель и тормозили друг друга до зависания.
7. **LLM + словарь в анализе рынка.** Модель находит навыки, которых нет в словаре; словарь страхует от пропуска очевидного. Ответы модели кэшируются, чтобы повторный отчёт не стоил новых запросов.
